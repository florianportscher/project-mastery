## Changes

**supabase**

- Structure: nothing to change. Every function, trigger function and table has a caller, the policies do not overlap and the grants match them.
- Seams: none changed (see left below).
- Lines: three `course_id` indexes on `kcs`, `exercises` and `topics` dropped, because the unique `(course_id, position)` key covers them. The empty `supabase/seed.sql` is gone (`config.toml` seed off, `CONTRIBUTING.md` fixed).

**chat**

- Structure: `Chat` (complexity 37) split into `StudentMessage` and `AiReply` in `components/chat-message.tsx`. `ReplyUsage` and `StoredReplyUsage` were two copies of one type; `usage` owns it now. `goalLabel` moved to `brief`, which owns `Goal`, and the Brief panel uses the same function.
- Seams: `replyUsage`'s `estimated` argument (always false) and `retryRateLimited`'s `wait` parameter (no caller passed it) removed.
- Lines: `respondInChat` stores a new message in one branch; one `courseId` variable instead of `courseId!` assertions; two comments moved to the code they describe and "learn session" became "Study session"; `replyStep`'s `inProgress` default (its caller always overrides it) removed.

**ingestion**

- Structure: one `PageUnit` type replaces `BatchUnit` and the copy `z.infer` made in `ai` (the generic on `unitsOnPages` is gone). `pageSource` and the image download moved from `parse-steps.ts` to `page-images.ts`. `course-language.ts` and `material-language.ts` became `domain/language.ts` with one shared `mostCommon` (file map in `knowledge-map.md` updated).

- Lines: `preparePages` computes the missing pages once, so its second update no longer repeats `parse_status` and `parse_failure`. `readBatch` complexity 22 -> 14 (`readEach`, `readAlone`; the `said` and `rows` helpers are gone, `lastUnitBefore` takes a page number). `missingPages` moved to `domain/pages.ts`.

**lib**

- Structure: `supabase/admin-brand.ts` merged into `supabase/types.ts`, which ended the only import cycle (15 importers updated). `deployedCommit` moved from `app-commit-env.ts` into `deployment-env.ts`. `daily-quota.ts` merged into `rate-limit.ts`.
