# Retro 2026-11-20: the two-shift workflow, and a cleanup audit

The maintainer asked for an audit of the whole repo and of its agent runs. This report replaces the retro planned around 2026-12-02.

Six read-only Sonnet agents covered six areas:

- the 8 `/build` sessions since 2026-11-09;
- the maintainer's time across 121 sessions since 2026-10-23;
- the harness;
- docs, CI and the repo;
- the production code, after `pnpm -s sweep`'s checks;
- the tests and the speed of the checks.

Costs are list prices from `pnpm -s retro`. Evidence is given as `session/agent:Lline`. The fixes are specs #342–#348.

## Findings

1. **Live-round slices are where the money still goes.** #279 s2 cost $11 plus $6.7 of player agents and ended at the weekly limit without a push. Its fixes are salvaged in #342. Fix (#343): a rounds slice commits and pushes after every round.
2. **The coordinator's `sleep 1800` loop re-arms itself.** In `eec32985`, 158 of 500 coordinator turns were sleeps ($2.03 of $5.89), and the shifts ended on a stale timer instead of the report. Fix (#343): one timer per running builder.
3. **`db:test` is red on every run**, so it carries no signal (#346).
4. **Refused commands:** about 60 per three sessions (#343: the `/tmp` exemption, `ready.sh`, `browser js`).
5. **The Stop hook ran `pnpm check` 936 times, for 287 minutes,** 198 of them in the main checkout, which was never clean because of two untracked files. Fix (#343): skip a state already seen green.
6. **Finish builders ran on Opus twice ($2.76).** Fix (#343): the default model.
7. **Escapes:** 3 of 22 PRs drew change requests, none about correctness:
   - #283's settings dialog, a UX call;
   - #305's PDF flicker: "not tried in a browser";
   - #323's roadmap wording.

   Red CI on build PRs was fixed before the report every time. Fix (#343): for a change the Student sees, the finish walks the `Try it` steps in the browser.

8. **Rejected fixes #253 and #263 broke a rule that lived only in agent memory** (prompt over code guards). Fix (#343): the rule moves into `builder.md`.

## Which steps earn their cost

- **Spec reviewer:** $2.90 over 21 diffs. It found real bugs in 8, for example #298's `pipefail`, #335's double recording and #336's upload row that could stay forever. Keep it.
- **Standards reviewer:** $1.60. Its findings are stale docs only. Cheap, so keep it.
- **Finish:** it applies about 14 review fixes. Its full re-checks repeat CI, but cheaply.
- **Live smoke check:** under $0.02 a run. #311 shows what skipping it costs.
- **Draft PR:** nobody reads it during a shift. Removed in #343; pushing after each slice still protects work that gets cut off.
- **Haiku coordinator, Sonnet default builder, verbatim prompts, the change-request flow ($0.60 for two rounds) and `cleanup.sh`/`setup.sh`:** work; leave them.
